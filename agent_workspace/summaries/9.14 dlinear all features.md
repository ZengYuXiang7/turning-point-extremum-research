# DLinear 全特征实验

## 实验口径

- 数据：16台广宁风机，15分钟采样，按时间70%/10%/20%切分。
- 基线：现有19通道 DLinear；通道之间不融合，功率输出只由功率通道直接产生。
- 全特征模型：`DLinearAllFeatures`，使用59个可训练通道，并在DLinear输出后学习跨特征线性投影。
- 特征：processed 的56个无缺失字段中排除训练段恒定的“传动链-液压站压力”；4个周期角度以sin/cos替换，最终59维。
- 训练：MSE、seed 2026、batch size 1024、最多100轮、validation scaled MSE选模、patience 10。
- 除特征口径与跨特征投影外，采样、窗口、切分、标签、损失、seed、选模和测试指标均不变。

## 结论

- 15分钟至2小时的五个视界，Acc30均提高，提升范围为1.74至3.20个百分点；2小时配置同时取得最大的Acc30提升和10.54 kW的MAE下降。
- 3小时及更长视界的Acc30没有稳定收益；12小时和24小时的MAE、RMSE明显变差。
- 长视界的validation最佳轮次集中在第1至3轮，说明当前“全特征 + 单层线性融合”很快开始损害泛化。
- 当前证据支持把全特征融合用于超短期至2小时，不支持直接替换3至24小时的19通道基线。
- 每个配置只有一个seed，不能做显著性检验；以上结论仅限本次seed 2026。
- 这不是纯粹的特征数量消融：基线不做跨通道融合，全特征变体同时增加了特征和跨特征投影。
